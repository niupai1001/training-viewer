# 大量指标选择与呈现 — 专项交互规格

**定位：** 本文件补充契约 C10，不替代 01 强制契约。截图（2026-11-03）的直接问题是上百个原始键在默认工作区平铺呈现，并混用单点结果与连续曲线。

## 1. 默认工作区（浏览器关闭）

左：单一实验列表。右上：状态、训练时长、Loss、Val Loss、最佳验证指标、学习率。右中：Train/Val Loss 同图、主验证曲线。右下：预测结果。右上角仅提供 `＋ 添加图表`（搜索图标与文字）与已有图表的小型菜单。

不允许在工作区顶部显示 `全部阶段 capacity combo_SWIR_pair train_A ...` 的标签海，也不允许把每个原始 key 渲染成芯片。

## 3. 点击后的行为

- 点击主图“添加图表”打开浏览器，选连续指标显示可合并性检查；确认后将其加入主区的新图表卡片，可更改标题、移动、隐藏、删除。
- 点击一次性评估项时，浏览器给出“查看结果表/散点”的建议，不提供隐含趋势的默认折线。
- 系统允许选择多个指标，超过建议绘图密度可提示分拆，不能静默截取前两个。不同单位/不同定义不自动叠加。
- 保存自定义组合，重新打开同一 Run 能恢复；切换 Run 保留原视图状态但不误用不相同指标键。
- 搜索时支持 `rmse`、`SWIR`、`SR_B6`、中文名称，搜索结果可筛选全部/已选；选中状态不因筛选而丢失。

## 4. 数据形态判定细则

- `point_count` 不是唯一判断依据。计算 `distinct_x_count`，且 X 必须在所选 `Step`、`Epoch`、`timestamp` 轴上可用。
- 单次结果视图汇总指标，保留来源原始路径、完整键、单位、值。一个点仍可按散点查看，不能默认连折线。
- `capacity`、`combo_SWIR_pair` 等只能先当路径结构识别，专业含义必须来自协议声明或用户确认。
- 新 TVLP 1.1 可声明 `metric_groups`，通过 prefix/group label/可选维度说明组织指标；历史日志不需要补写 metadata。
