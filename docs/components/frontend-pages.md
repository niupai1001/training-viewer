# 组件说明：前端页面组合（Pages）

## 一句话说明

把查询 API、图表、表格与产物视图组合成页面：监控、实验库、运行详情、实验对比、预测结果、设置与诊断；一级导航只保留前三个，产物预览内嵌运行页，目录与诊断进入高级设置。页面只做展示与交互，不直接解析日志或操作数据库。

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文功能名 | 前端页面组合 |
| 代码名 | `OverviewPage`、`ExperimentsPage`、`RunDetailPage`、`ComparisonPage`、`ResultsPage`、`DiagnosticsPage` |
| 源文件 | `frontend/src/pages/` |
| 所属模块 | 前端页面 |
| 上游 | `AppShell` 哈希路由；下游 | 组件与 `/api/v1/*` |
| 首次引入版本 | 1.0.0 |

## 页面职责

| 页面 | 中文名 | 输入 | 输出 / 关键行为 |
|---|---|---|---|
| `OverviewPage` | 监控 | 最近/活跃运行、自动候选指标、根目录 | 直接看 Loss/验证曲线、Epoch 进度、最新产物；高级设置折叠目录/诊断/保存视图 |
| `ExperimentsPage` | 实验库 | 筛选参数、运行列表、facets | 默认精简列、高级筛选折叠、排序、列显隐、批量选择、收藏、快捷对比 |
| `RunDetailPage` | 运行详情 | `run_id` | 备注/收藏；自动推荐指标、加入对比、内嵌最新产物、五个标签 |
| `ComparisonPage` | 对比 | `runs`、可选 `series`/`axis`/`view` | 多运行曲线、Best/Last、超参数差异、导出、按 ID 恢复完整保存视图 |
| `ResultsPage` | 预测结果 | `run`、可选 `tag` | 运行/标签选择、样本对照、全部产物（从运行页进入，不在主导航） |
| `DiagnosticsPage` | 设置与诊断 | 诊断数据、适配器、同步状态 | 根目录管理、目录问题、run_id 冲突、问题运行、重新扫描 |

## 主要处理流程

1. `App.tsx` 建立 SSE 订阅，把递增的版本号放入 React Context。
2. `AppShell` 用哈希路由选择页面；项目树来自 `/projects`。
3. 页面使用 `useApi` 加载数据；依赖列表包含实时版本（运行中的页面会在 SSE 通知后重新查询）。
4. 页面把数据分发给图表、表格、产物组件；用户操作调用 REST 并刷新。
5. 地址栏保存可分享的选择（运行 ID、指标、横轴、标签），保存视图使用同一格式。

## 交互与可访问性

- 所有按钮有文字标签或 `aria-label`；弹窗支持 Escape 关闭，并使用 `role="dialog"`。
- 状态、方向、单位、活动时间均有中文 tooltip。
- 表格使用 `scope="col"` / `scope="row"`；图像有替代文本。
- 响应式布局：窄屏侧边栏变为抽屉，表格可横向滚动。

## 配置与依赖

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 实时刷新合并 | 600ms | SSE 高频通知合并 |
| 实验列表页大小 | 50 | 分页 |
| 列显隐存储键 | `training-viewer.experiment-columns.v1` | localStorage |
| 对比最多运行数 | 12 | 页面限制 |

依赖：React、ECharts、各组件与 `api/client.ts`。没有状态管理库或路由库；使用哈希路由（`navigation/route.ts`）。

## 如何验证

- `npm run typecheck`。
- Chrome 无头加载各页面，检查 `document.body.innerText` 与无 `Runtime.exceptionThrown`。
- 手工：添加目录 → 查看运行 → 对比 → 结果 → 诊断的完整路径。
- 保存/恢复对比视图；刷新页面后地址栏状态保持。

## 已知限制与回退

- 没有前端单元测试框架；关键数据规则由后端测试覆盖，页面通过类型检查与无头浏览器验证。
- 哈希路由不提供服务端多页面路由；直接访问 `#/...` 可用，刷新保持同一页面。
- 没有离线缓存；SSE 断开后页面不会自动轮询，但用户操作或重连会刷新。
- 回退：页面只读展示，删除前端构建产物会退回“前端未构建”提示页，API 仍可用。

## 名称解释

- 哈希路由：用 URL `#` 后部分表示页面，不需要服务器路由。
- `useApi`：项目内的小型数据加载 Hook。
- localStorage：浏览器本地存储，用于列显示偏好。
