# 组件说明：预测结果对照器（PredictionComparisonViewer）

## 一句话说明

按样本与训练轮次展示原图、真实标签、预测结果的并排或透明叠加视图；只显示 `artifact` 事件引用的图像，不生成预测、不做跨运行自动对齐、不执行 HTML。

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文功能名 | 预测结果对照器 |
| 代码名 | `PredictionComparisonViewer` |
| 源文件 | `frontend/src/components/PredictionComparisonViewer.tsx` |
| 所属模块 | 前端结果浏览 |
| 上游 | 预测结果页面；下游 | 图像 `<img>`、表格预览对话框、下载链接 |
| 首次引入版本 | 1.0.0 |

## 为什么需要它

分隔实验最直观的证据是同一张图、同一轮次下“原图 / 标签 / 预测”的对照。查看器只使用协议中显式的 `group_id`、`sample_id`、`epoch` 和 `role` 关联，不按文件名猜测，也不跨运行自动配对。

## 输入与输出

| 方向 | 名称 | 类型 | 说明 |
|---|---|---|---|
| 输入 | `groups` | `ArtifactGroup[]` | 来自 `/artifact-groups`，每个分组含 `roles` |
| 输入 | `runName` | 字符串 | 页面显示的运行名 |
| 输入 | 用户操作 | 点击/下拉/滑杆 | 选择样本、Epoch、并排/叠加、透明度 |
| 输出 | 图像面板 | DOM | 按角色排序的 `<img>` |
| 输出 | 叠加视图 | DOM | 底层图 + 透明叠加层 |
| 输出 | 尺寸不一致提示 | 文本 | 两张图实际宽高不同时显示 |
| 输出 | 表格预览/下载 | 对话框/链接 | 非图像产物按文件处理 |

## 主要处理流程

1. 从分组中提取唯一样本（`sample_id`，缺失时用 `group_id`）。
2. 选中样本后，按 `epoch` 列出该样本的可用分组，默认最后一个 Epoch。
3. 每个分组按角色排序：`input`（原图）→ `ground_truth`（真实标签）→ `prediction`（预测）→ 其它角色。
4. 并排模式：每个角色一个卡片，显示图片、文件名、Epoch、时间；文件缺失显示占位与下载入口。
5. 叠加模式：默认底层为真实标签、叠加层为预测；允许切换两个角色，透明度 0–100%。
6. 图像 `onLoad` 记录自然宽高；底层与叠加层尺寸不同时提示可能位移，并按等比例拉伸显示。
7. 非图像角色（CSV 混淆矩阵等）提供预览/下载入口。
8. 所有图像均使用受控 `content_url`，不插入 HTML。

## 配置与依赖

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 默认显示模式 | 并排 | 至少两张图像时可切换叠加 |
| 默认叠加透明度 | 65% | 0–100% |
| 叠加至少图像数 | 2 | 否则按钮禁用 |
| 图像格式 | png/jpg/jpeg/webp/gif/bmp | 其它文件显示下载/预览 |

依赖：React、`ArtifactGroup` 类型、`TablePreviewDialog`。无额外第三方库。

## 和旧实现相比改变了什么

初始实现，无旧版本。V1 使用协议中的 `group_id` 与 `sample_id`，并明确不跨运行自动对齐；跨模型对比通过分别打开运行结果或后续扩展实现。

## 如何验证

- 手工/无头浏览器：`#/results?run=<wavelength 示例>&tag=segmentation-preview`，确认两张图像并排，切换叠加与透明度可用。
- `tests/test_api.py::test_artifact_listing_groups_content_and_table_preview` 验证分组与角色。
- 缺失产物：删除示例图片后，界面显示占位而非破图。
- 尺寸不一致：使用不同尺寸图片的示例分组，确认提示出现。

## 已知限制与回退

- 只按 `epoch` 切换同一 `sample_id` 的产物；没有跨运行自动比较。
- 叠加只支持两张图，不计算差异图、不将标签颜色映射到预测。
- 大图在浏览器中按容器缩放；没有图像解码/分块服务。
- 回退：关闭页面；图像只读显示，不影响原始文件。

## 名称解释

- `role`：产物角色，如 `input`、`ground_truth`、`prediction`。
- `group_id`：把同一组对照图像关联起来的标识。
- 叠加：把一张图以透明度覆盖在另一张图上。
