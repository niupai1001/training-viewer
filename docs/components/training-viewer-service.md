# 组件说明：查看器应用服务（TrainingViewerService）

## 一句话说明

协调根目录配置、目录扫描、增量索引、状态刷新、冲突记录和 SSE 通知；不实现 HTTP 路由细节，也不解析具体日志格式。

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文功能名 | 查看器应用服务 |
| 代码类名 | `TrainingViewerService` |
| 源文件 | `src/training_viewer/service.py` |
| 所属模块 | 应用服务 |
| 上游 | FastAPI 应用、CLI；下游 | 扫描器、索引器、查询层、监听器 |
| 首次引入版本 | 1.0.0 |

## 为什么需要它

HTTP 路由与后台线程都需要“扫描一次目录”的能力。如果各自实现，容易并发写入游标或产生重复扫描。服务层用一把同步锁串行化同步过程，并统一维护版本号与订阅者。

## 输入与输出

| 方向 | 名称 | 类型 | 说明 |
|---|---|---|---|
| 输入 | 应用路径 | `ApplicationPaths` | 数据目录、数据库、静态资源 |
| 输入 | 根目录路径 | 字符串 | `add_root` / `remove_root` |
| 输入 | 时钟/间隔/自定义注册表 | 可选 | 测试注入或插件 |
| 输出 | 根目录列表 | `dict` | 供 API 与插件 |
| 输出 | 同步结果 | `dict` | 版本、变更运行、发现数量、问题数 |
| 输出 | SSE 消息 | `dict` | 版本、变更运行、诊断是否变化 |
| 输出 | 健康状态 | `dict` | 应用名、版本、最后同步时间、数据目录 |

## 主要处理流程

### 同步 `synchronize()`

1. 获取同步锁，读取全部根目录。
2. 判断是否需要全量发现：首次、`force_full`、距上次全量 ≥300 秒，或已知 Run 目录消失。否则只对已知 Run 目录重新发现。
3. 全量时对每个根目录调用扫描器并聚合目录级问题；增量时只拿到已知 Run 的新读数。
4. 按 `run_id` 去重并检测冲突（同一目录允许多个通用文件 Run 共存）。
5. 对每个发现的 Run 调用索引器；单个 Run 异常记录问题并继续。
6. 对不在本次发现集合中的运行标记“目录不可访问”，不删除索引。
7. 刷新所有运行状态（心跳超时会改变状态）。
8. 整体替换 `run_conflicts` 与目录级问题。
9. 计算诊断/问题签名；有运行变化、诊断变化或首次同步时递增版本并发布 SSE。
10. 记录最后同步时间/错误。

### 根目录

- `add_root`：解析为绝对目录、拒绝不存在的路径、重复添加返回已有记录、持久化后立即同步。
- `remove_root`：删除根目录配置及其运行索引；原始文件不动，备注不删除但随运行隐藏。
- 根目录变化会刷新 watchdog 监听。

### 实时订阅

- `subscribe(loop, queue)` / `unsubscribe` 供 SSE 使用。
- `_publish` 通过 `loop.call_soon_threadsafe` 投递；队列满时丢弃最旧消息，避免阻塞训练日志读取。
- 后台线程由 `LogUpdateWatcher` 驱动。

## 配置与依赖

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `scan_interval_seconds` | 2.0 | 传给监听器 |
| `full_scan_interval_seconds` | 300.0 | 完整目录树发现兜底间隔；目录结构事件/手动刷新可提前 |
| `data_dir` | `ApplicationPaths` 解析 | SQLite 与实例文件 |
| `source_adapter_registry` | 内置注册表 | 传入自定义注册表会**替换**内置来源；需要内置来源时先用 `build_builtin_source_adapter_registry()` 再注册插件 |
| 时钟 | UTC now | 测试可注入 |

依赖：扫描器、索引器、查询层、监听器、SQLite。无第三方 Web 依赖（HTTP 层单独）。

## 和旧实现相比改变了什么

初始实现。V1 明确：

- 目录移动保留索引并标记不可访问，而不是删除运行；
- 重复 `run_id` 保留一个并报警；
- 诊断签名变化也触发 SSE，而不只推送指标变化；
- 支持注入自定义来源注册表，便于插件与测试。

## 如何验证

- `tests/test_indexing.py` 中的服务级测试（根目录、冲突、移动目录、备注保留、自定义适配器）。
- `tests/test_api.py` 的根目录增删与同步触发。
- 手工：重复 `training-viewer open examples` 应复用实例，API 版本递增、不重复运行。

## 已知限制与回退

- 同步是全局串行；增量只重读已知 Run，完整发现每 300 秒兜底。大规模目录可调整相关间隔或拆分根目录。
- 移除根目录会删除该根目录的运行索引（备注保留但不显示）；重新添加后重建索引。
- 回退：停止进程；删除索引数据库可重建。原始日志不参与任何删除操作。

## 名称解释

- 根目录：用户显式添加、允许扫描的目录。
- SSE：Server-Sent Events，服务器发送事件。
- 冲突：同一 `run_id` 出现在多个目录。
