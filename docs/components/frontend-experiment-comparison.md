# 组件说明：实验对比页面（ComparisonPage）

## 一句话说明

让用户选择多个运行和指标，叠加查看曲线、最佳/最终值、关键字段与超参数差异，并在不可比时给出明确警告；不修改运行数据，也不自动替用户下结论。

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文功能名 | 实验对比页面 |
| 代码名 | `ComparisonPage` |
| 源文件 | `frontend/src/pages/ComparisonPage.tsx` |
| 所属模块 | 前端页面 |
| 上游 | 侧边栏“实验对比”、实验管理批量选择、保存的对比视图；下游 | `RunSelector`、`MetricChart`、`BestLastTable`、`ComparisonTables`、API |
| 首次引入版本 | 1.0.0 |

## 为什么需要它

比较多个实验不是把曲线画在一起：要处理不同指标定义、单位、数据集、任务类型，缺失指标不能插值，最优值必须来自原始数据。页面把这些规则显式呈现给用户，而不是静默排名。

## 输入与输出

| 方向 | 名称 | 类型 | 说明 |
|---|---|---|---|
| 输入 | 地址栏 `runs` | 逗号分隔 run_id | 初始选择，最多 12 个 |
| 输入 | 地址栏 `series` | 逗号分隔指标键 | 保存视图/外链可指定 |
| 输入 | 地址栏 `axis` | 横轴 | 可选 |
| 输入 | 用户操作 | 勾选/指标点击/显示设置 | 选择运行、指标、平滑、对数轴 |
| 输出 | 图表 | ECharts | 每个指标一张图，多运行叠加 |
| 输出 | 表格 | HTML | Best/Last、运行字段、超参数差异 |
| 输出 | 下载 | CSV/JSON | `POST /compare/export` |
| 输出 | 保存视图 | API | 名称 + 运行/指标/横轴/平滑参数 |

## 主要处理流程

1. 读取地址栏的 `runs`，加载所有运行列表。
2. 并行请求所选运行的指标键，构建可用指标并集，记录每个指标出现在多少个运行中。
3. 用户选择指标后调用 `/compare/query`。
4. 对每个指标渲染一张 `MetricChart`（同组图表同步悬停/缩放），并展示该指标的警告。
5. 展示 `BestLastTable`：只有 `ranking_allowed` 才标记最优；否则显示“不可直接排名”。
6. 展示运行关键字段与超参数差异表（默认只显示差异项，可搜索）。
7. 支持 CSV/JSON 导出；导出请求包含横轴、指标、最大点数和显示参数。
8. 支持保存对比视图；保存后可在总览页恢复。
9. 每次选择变化用 `history.replaceState` 更新地址栏，避免产生大量历史记录。

## 可比性呈现

- 指标并集显示“出现于 N/M 个运行”，部分运行缺失时明确提示。
- 单位、数据集、定义、任务类型不一致时，`series.warnings` 直接展示；`ranking_allowed=false` 时不标“最优”。
- 不同运行长度不截断、不插值；每条运行保留自己的点集。

## 配置与依赖

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 最多选择运行 | 12 | 界面限制，接口支持 50 |
| 最大返回点 | 1500 | 每个运行-指标 |
| 默认平滑 | 不平滑，窗口 5 | 仅影响显示 |
| 默认主要指标 | 全部运行都有的 val 方向指标，否则第一个指标 | 用户可改 |

依赖：React、`RunSelector`、`ChartControls`、`MetricChart`、`BestLastTable`、`HyperparameterDiffTable`、`RunFieldsTable`、`api`。

## 和旧实现相比改变了什么

初始实现。首轮验证修正：地址栏指定指标时不再被自动默认选择覆盖（保存视图恢复正确）；跨任务类型比较增加警告并禁止自动排名。参见[变更记录 0002](../changes/0002-first-verification-fixes.md)。

## 如何验证

- Chrome 无头加载 `#/compare?runs=<两个 SegFormer 运行>&series=val/miou&axis=epoch`，确认显示两张运行曲线、Best 0.52 vs 0.61、超参数差异 3 项，且无控制台异常。
- `tests/test_api.py::test_compare_marks_comparable_and_shows_hyperparameter_differences`。
- `test_compare_is_not_ranked_when_dataset_or_unit_differs`。
- 手工：保存视图 → 总览恢复 → 指标与横轴保持。

## 已知限制与回退

- 指标并集最多显示后端返回的全部指标；大量运行时页面会较长。
- 超参数差异只比较 `run.json.config`；模型/数据集/种子在单独的关键字段表中。
- 图表平滑为客户端显示，导出数据包含平滑参数但不包含平滑后的数值。
- 回退：直接关闭页面；保存视图可删除，不影响运行数据。

## 名称解释

- 可比性：单位、数据集、指标定义和任务一致，允许直接比较。
- 排名：使用原始 Best 值标记最优；不可比时不排名。
- 保存视图：保存运行集合与显示参数，不复制数据。
