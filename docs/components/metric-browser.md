# 指标浏览器（MetricBrowserDrawer）

## 职责

默认工作区不再把所有指标键渲染成按钮。用户点击“＋ 添加图表 / 指标”打开侧滑抽屉，在服务端目录中搜索、按语义组和阶段筛选、分批加载，并显式加入新图或当前图。

## 输入 / 输出

- 输入：`runId`、已有自定义图表列表、是否打开。
- 输出：选中的 `MetricCatalogItem[]` 与目标图表 id；实际图表配置由 `TrainingOverview` 写入浏览器本地用户状态。
- 不修改原始日志或索引。

## 行为

- 搜索覆盖中文显示名、原始键、说明、分组路径；大小写不敏感。
- 分类页签使用 `semantic_group`，阶段是独立筛选；`capacity`/`combo_*` 只作为路径，不当作阶段或科学定义。
- 每项显示可读名、原始键、点数、不同有效 X 数、可用横轴、单位、单点标签、定义来源。
- 每页 40 项，可“加载更多”；不一次渲染全部候选。
- 选中集合与搜索/分页解耦，搜索变化不清空已选。
- 连续指标可新建折线图或加入同单位/同轴的当前图；单点指标生成评估表；单位不兼容时拒绝合并并说明原因。
- 抽屉关闭时清空本次选择；图表配置通过 `TrainingOverview` 持久化到 `localStorage`，按 Run id 区分。

## 边界

- 当前没有独立用户指标定义编辑 UI；“定义未提供”仍可搜索和查看。
- 结构化组合维度的热力图未实现；单点先以表格呈现。
- 自定义视图保存在浏览器本地用户状态，而不是写入 `index.sqlite3`；切换 Run、刷新页面、重建索引不会清除，但换浏览器/清站点数据会丢失。
- 当前没有虚拟列表；1,000 指标时 DOM 约 700 节点（含页面其他部分），因为只加载 40 项。
