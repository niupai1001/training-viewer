# 组件说明：指标曲线组件（MetricChart）

## 一句话说明

把一组指标点渲染为可缩放、可平滑、可导出 PNG/SVG 的 ECharts 曲线；只负责显示与客户端平滑，不查询数据、不计算 Best/Last、不改变原始记录。

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文功能名 | 指标曲线组件 |
| 代码名 | `MetricChart` |
| 源文件 | `frontend/src/components/MetricChart.tsx` |
| 所属模块 | 前端图表 |
| 上游 | 运行详情指标页、实验对比页；下游 | ECharts Canvas / SVG 导出 |
| 首次引入版本 | 1.0.0 |

## 为什么需要它

训练指标需要在高密度点、多个会话、不同单位和不同横轴下保持可读。把图表封装成单一组件，保证运行详情和多实验对比使用相同的平滑、缩放、导出与空数据处理方式。

不负责：请求数据、持久化偏好、判断指标是否可比、计算最佳/最终值。

## 输入与输出

| 方向 | 名称 | 类型 | 说明 |
|---|---|---|---|
| 输入 | `title` / `subtitle` | 字符串 | 指标名、单位/方向/定义说明 |
| 输入 | `lines` | `ChartLine[]` | 每条线包含 id、标签、点、单位 |
| 输入 | `axis` | `global_step` / `epoch` / `timestamp` | 横轴 |
| 输入 | `smoothing` | `none` / `moving_average` / `ema` | 客户端显示平滑 |
| 输入 | `smoothingWindow` | 2–50 | 平滑窗口 |
| 输入 | `logScale` | 布尔 | 对数轴；存在非正值时自动回退线性并提示 |
| 输入 | `showRaw` | 布尔 | 平滑时同时绘制原始曲线 |
| 输入 | `group` | 字符串 | 同组图表同步悬停/缩放 |
| 输入 | `downsampled` | 布尔 | 是否显示抽样提示 |
| 输出 | 图表 | DOM/Canvas | 折线、图例、缩放条、提示框 |
| 输出 | 下载 | PNG/SVG | 由 `getDataURL` 或 SVG 渲染器生成 |

## 主要处理流程

1. 过滤 `x` 为空的点，按连续 `session_id` 拆分为多条子曲线；多会话时图例带“会话 N”。
2. 对每条子曲线应用客户端平滑：
   - 移动平均：包含当前点在内的尾部窗口均值；
   - 指数移动平均：`alpha = 2/(window+1)`；
   - 不平滑：原样。
3. 平滑开启且“显示原始曲线”时，额外绘制低透明度原始线，并在 tooltip 中忽略原始线。
4. 计算是否存在非正值；对数轴请求但存在非正值时改用线性轴并显示提示。
5. 构建 ECharts 配置：数值轴、图例、轴提示、inside + slider 数据缩放、最小/最大分桶后的数据。
6. 挂载时 `echarts.init`，用 `ResizeObserver` 跟随容器宽度；同组图表 `echarts.connect(group)`。
7. 导出：
   - PNG：Canvas `getDataURL`，2 倍像素比；
   - SVG：临时 SVG 渲染实例生成字符串，Blob 下载。

## 配置与依赖

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `height` | 380 px | 图表高度 |
| 平滑默认 | 不平滑，窗口 5 | 由 `ChartControls` 控制 |
| 调色板 | 10 色 | 同一指标的不同运行/会话循环使用 |
| 最大显示指标数 | 运行详情 6 条 | 页面限制，避免大量图表 |
| 最大对比运行数 | 12 个 | 页面限制 |

依赖：`echarts`（Apache-2.0）、React、`utils/smoothing.ts`、`utils/download.ts`。

## 和旧实现相比改变了什么

初始实现。首轮验证修正了横轴名称与缩放条重叠的问题（增大底部网格、把名称下移），并增加“多会话分段”和“非正值对数轴回退”提示。

## 如何验证

- `npm run typecheck`。
- Chrome 无头验证：加载 `/runs/<id>`，页面无 `Runtime.exceptionThrown`，曲线渲染；切换 Epoch/时间轴、平滑、对数轴。
- 手工：导出 PNG 与 SVG，确认文件能打开；比较页面两个图表悬停同步。
- 前端没有单元测试框架；平滑函数为纯函数，逻辑简单，关键数据正确性由后端测试与人工检查覆盖。

## 已知限制与回退

- 平滑在浏览器端对**返回的抽样点**计算，百万点场景下与对原始点平滑可能略有差异；界面明确标注“仅影响显示”。
- 导出 SVG 使用独立临时实例，不包含 dataZoom 组件的交互状态。
- 未实现 LTTB；使用最小-最大分桶。
- 回退：移除图表组件或改用表格显示，不影响数据接口。

## 名称解释

- ECharts：Apache ECharts 图表库。
- EMA：指数移动平均。
- 数据缩放（dataZoom）：图表内部缩放与底部滑动条。
- 多会话分段：按 `session_id` 拆分曲线，避免断点续训的 Step 回退被连成一条线。
